# 基础依赖（Python 3.9 测试通过）
numpy
scipy
matplotlib
PyQt5
PyYAML
pywin32          # 仅 Windows：win32ui 文件对话框
PyVISA           # VISA 仪器通信

# 硬件厂商 SDK / 驱动
pipython         # PI E7273 压电位移台（Physik Instrumente）
pulsestreamer    # Swabian Instruments Pulse Streamer 任意波形发生器
TimeTagger       # Swabian Instruments Time Tagger Ultra（需厂商安装包）
windfreak        # Windfreak SynthHD 微波源

# 说明：
# 1) TimeTagger 通常需从 Swabian Instruments 官网下载对应 Python 版本的
#    安装包（wheel / exe）后安装，pip 源中可能不可用。
# 2) pipython 需配合 PI 的 GCS DLL（PI_GCS2_DLL）使用。
# 3) 无硬件时程序可启动，但各实验界面会提示设备连接失败。
